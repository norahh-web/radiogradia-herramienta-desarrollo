Radiografía de Bootstrap

¿Qué es Bootstrap?

Bootstrap es un framework de CSS y JavaScript que sirve para maquetar páginas web responsive de forma rápida, con una rejilla y componentes ya hechos.

Nació dentro de Twitter y su primer nombre fue Twitter Blueprint.

Datos rápidos

  • Creadores: Mark Otto y Jacob Thornton
  • Primera versión pública: 19 de agosto de 2011
  • Licencia: MIT
  • Tecnologías: HTML, CSS y JavaScript
  • Web oficial: getbootstrap.com

Un ejemplo de uso

Con dos clases, Bootstrap le da estilo a un botón sin escribir nada de CSS:

<button class="btn btn-primary">Enviar</button>

Más información

Instalación: se puede enlazar por CDN o instalar con npm.

Ventajas: ahorra tiempo, es responsive y tiene mucha documentación.

Extensiones: iconos de Bootstrap y temas de la comunidad.
